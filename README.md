## 🚀 How to Enable GitHub Pages (Instant Web Hosting)

To make your study portal accessible on any laptop, tablet, or phone via GitHub:

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository:
   * Go to **Settings** ➔ **Pages** (under Code and automation in sidebar).
   * Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
   * Under **Branch**, select `main` and `/ (root)`, then click **Save**.
3. Your web portal will be live in ~60 seconds at:
   `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/`
